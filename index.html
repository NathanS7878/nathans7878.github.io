MiniDynamo — KV-cache-aware LLM inference router

A distributed inference-serving system modeled on NVIDIA Dynamo: an async Rust frontend (axum/Tokio) routing OpenAI-compatible requests across a pool of Python model workers. It tokenizes each prompt, hashes it into prefix-dependent blocks, and routes to the worker holding the longest cached prefix — cutting time-to-first-token 23% versus round-robin at 91% cache reuse.

Rust·Python·Distributed systems
kv-aware routing
02

Gravity — 3D N-body orbital simulator

A real-time Newtonian gravity simulation in C++. Started as a headless 2D integrator writing orbits to CSV, then grew into a full 3D visualizer built with Raylib — softened force computation, semi-implicit Euler integration, and bodies orbiting a central mass in a perspective camera.

C++·Raylib·Physics
n-body simulation

Snake — grid renderer & game loop

The classic, rebuilt from scratch on a Raylib game loop. A fixed-timestep grid renderer drives the board, with movement, growth, and collision handled cell-by-cell — an exercise in game state, input handling, and immediate-mode drawing.
